# Rootkit

**Status:** Built.

Malware the AI installs in the robo taxis. A taxi with a rootkit is not used until someone cleans it. A player takes the job in Town repairs and cleans the rootkit by cracking its code at a public terminal (the Code cracker). The taxi stand shows whether the taxis are clean. A cleaning holds for a while, then the AI gets back in.
