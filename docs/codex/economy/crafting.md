# Crafting

**Status:** Open: an idea, not decided. The workbench does the battery swap.

The game is about technology, so there is a lot to repair and build: build your phone, laptop and gaming rig; repair and upgrade drones; repair your EMP defences. You need wire, cooling parts, CPU, RAM and GPUs to build a laptop, and more of better quality for a gaming rig. Some items slot into others to upgrade them: a better power supply is a longer battery.
