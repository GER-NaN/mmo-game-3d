# Coverage

**Status:** Decided, not built.

How much the AI can see in a place. It is dense in towns, thin in the wild, and there is none in the desert.

Coverage matters most for a data centre: built inside coverage, the AI sees it going up and acts against it (a tax that makes it cost more, a slowdown, or complete withdrawal); built somewhere remote, it is safe. Out in the wild there is also no cell service, so no map and no GPS.
