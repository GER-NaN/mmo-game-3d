# Server region

**Status:** Decided, not built. One region at first.

Servers stand in different parts of the world for latency: East Coast, West Coast, Asia, South America, Europe. One canonical game world overlaps all of them. Each server is somewhere, with its own clock and time zone, and lighting and routines follow it.

Unsolved: regions progress at different speeds. A worldwide event triggered by Europe is unfair to Asia; regions at their own pace spoil Europe's future for Asia.
