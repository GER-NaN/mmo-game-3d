# Skill

**Status:** Built.

A narrow activity that earns experience when you do it, almost RuneScape-like: every N distance walked, every N jumps, each electric box repaired. A higher skill gives small rewards in play, and can change what the body does. Skills are private unless you turn on "Show Skills".

Built: Agility, Hacking, Workbench, Field repair, Electrical repair, Gardening. Named: Drone control, Networking, Social. "Skill" is the working word; a better one is not chosen.
