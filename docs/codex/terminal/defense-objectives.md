# Defense Objectives

**Status:** Built. One objective, Agent Defense.

The general name for fighting the AI inside the terminal. They take many forms: operate a CCTV camera to spot drones, the electric wire-cutting game, search archive data for clues on the Prompt, monitor network activity for intrusions. Some are part of the campaign, some are puzzles, some are mainstays with their own leaderboards. The player never hears "mini-game".

Some need two players, and the big version is distributed compute, a hack that needs a hundred players sharing GPU power.
