# Terminal OS

**Status:** Built. Its look is not settled.

The simple, specialised OS of the in-game terminal. Every feature of the game is an app: Chat, Who's online, Whois, Town repairs, Town log, Code cracker, Town cameras, Status board, Exchange rate, Defense Objectives, and locked ones (Remote monitoring, FPV drone surveillance, Market prices, Crypto wallet, Meeting room, Transit schedule). Which apps you get depends on the device: a phone has only simple ones.

It looks somewhat like a modern OS with a pixel vibe. Public terminals are simpler, a player's own desktop is advanced, data centre terminals are for one function.
