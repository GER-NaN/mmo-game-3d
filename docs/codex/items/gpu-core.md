# GPU core

**Status:** Built. It is an item; its use as a currency is not built.

Compute. Spend it, trade it, or put it to work. GPU, RAM and CPU are a currency in themselves, consumable, and items: a physical currency. A GPU is expensive; a high-tier one costs tens of thousands of dollars in real life. The GPU tier is an equipment line for terminal power, and a better GPU hacks faster. GPUs wear with terminal use.
