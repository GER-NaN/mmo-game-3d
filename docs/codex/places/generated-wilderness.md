# Generated wilderness

**Status:** Decided, not built. Its name is open.

The ring beyond the known wilderness, generated and different each time, because nobody hand-places trees for a map the size of the United States. It is where a grinder goes: hundreds of GPU units from the rogue drones roaming the forest. Small towns are sprinkled through it. Coordinates stay real: heading west from Philadelphia, your west coordinate keeps rising until you near Chicago. "Unmapped area" is a bad name for it; the name is not chosen.
